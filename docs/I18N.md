# MoonLander Internationalization (i18n) Architecture

MoonLander uses a lightweight, fully typed, zero-runtime-overhead i18n scaffolding designed for Next.js App Router and client hydration.

## 1. Supported Locales

| Locale Code | Language | Native Name | Status |
| :--- | :--- | :--- | :--- |
| `en` | English | English | **Complete (Reference Default)** |
| `es` | Spanish | Español | Scaffolding Ready |
| `fr` | French | Français | Scaffolding Ready |
| `ja` | Japanese | 日本語 | Scaffolding Ready |

---

## 2. Directory Structure

```
src/lib/i18n/
├── types.ts           # TypeScript schema defining all required keys
├── index.ts           # useTranslation() hook and locale resolvers
└── locales/
    ├── en.ts          # Canonical English strings
    ├── es.ts          # Spanish translations
    ├── fr.ts          # French translations
    └── ja.ts          # Japanese translations
```

## 3. How to Add a New Language (e.g., German `de`)

Follow these four steps to contribute a new language:

### Step 1: Create the Translation Dictionary
Create `src/lib/i18n/locales/de.ts`:
```ts
import type { TranslationDictionary } from "../types";

export const de: TranslationDictionary = {
  common: {
    appName: "MOONLANDER",
    tagline: "Jede Mission beginnt mit einer Entscheidung.",
    loading: "Telemetriedaten laden...",
    save: "Speichern",
    cancel: "Abbrechen",
    close: "Schließen",
    back: "Zurück",
    next: "Weiter",
    continue: "Fortfahren",
    confirm: "Bestätigen",
    offline: "OFFLINE",
    online: "ONLINE",
    updateAvailable: "Update verfügbar",
    dismiss: "Verwerfen",
  },
  // ...implement nav, stages, hud, descent, settings sections
};
```

### Step 2: Register in `src/lib/i18n/index.ts`
Import the new dictionary and add it to `LOCALES`:
```ts
import { de } from "./locales/de";

export const LOCALES = {
  en: { name: "English", nativeName: "English", dict: en },
  // ...
  de: { name: "German", nativeName: "Deutsch", dict: de },
};
```

### Step 3: Verify Type Safety
Run the TypeScript compiler:
```bash
npm run typecheck
```
If any translation key is missing or mistyped, TypeScript will alert you at compile time.

## 4. Usage in React Components

```tsx
import { useTranslation } from "@/lib/i18n";

export function FlightHud() {
  const { t, locale, setLocale, supportedLocales } = useTranslation();

  return (
    <div>
      <h1>{t("common", "appName")}</h1>
      <p>{t("common", "tagline")}</p>
      
      {/* Language Switcher */}
      <select value={locale} onChange={(e) => setLocale(e.target.value)}>
        {supportedLocales.map((l) => (
          <option key={l.code} value={l.code}>{l.nativeName}</option>
        ))}
      </select>
    </div>
  );
}
```
